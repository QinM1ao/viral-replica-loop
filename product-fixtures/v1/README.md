`assets/fixtures/v1/` of the private Plugin Package. The tiny Y4M files are hand-authored; the PCM,
four-second 320x480 illustrated source, its 5fps evidence frames, WAV, and exact audio-bearing
finalization MP4s are deterministically synthesized with local tools. The
sealed Wujie request/response pair exercises the production video-understanding seam without
opening the network. Sealed independent-checker verdicts are bound to exact stage fingerprints,
the source/current storyboards depict the same ordered open-texture-wipe story with a
necessary-only product substitution, and distinct clean/burned-in MP4s drive subtitle branches.
The fixtures contain no real person,
customer, historical Job, live provider output, or Development Workspace material.

`fixture_origin.json` is authoritative for provenance and file digests. `suite.json` binds both
LegacyLayout and CanonicalLayout to the same Runtime Contract, Effective Profile components,
zero-spend approval, reference order, and expected logical roles.

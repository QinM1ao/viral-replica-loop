# Trust Report

## Authority

The Skill may read user-supplied media, write only the bound Job's `work/minimax-h3` artifacts, call configured ElevenLabs and Wujie endpoints, and run local media tools. It keeps credentials in process or Workspace configuration and excludes them from requests saved for inspection.

## Paid Boundary

Timeline extraction, prompt writing, packaging, public-URL checks, and Task Key polling do not authorize paid generation. A direct MiniMax H3 generation request authorizes every required unit of the current explicit Job once. The Skill creates no automatic retry.

## Recovery

Every attempt has an independent request, Task Key, provider response, and raw output. Query-layer errors remain bound to the same key. Finishing preserves the raw provider file and the approved audio master.

# Output Quality Scorecard

| Dimension | Requirement |
| --- | --- |
| Invocation | MiniMax H3 must be explicitly selected; generic replication stays on `viral-replica`. |
| Timeline | ElevenLabs controls speech timing; measured pixel cuts control visual timing; complete source coverage is exact once. |
| Prompt | Six Ref2VA sections, closed labels, time-axis Shots, and audio retention marker matching the real mix. |
| Request | TaskCode, model, nested param, asset roles, media reachability, duration, ratio, and resolution pass before submission. |
| Cost | At most one paid Task Key per approved unit and no automatic retry. |
| Delivery | Raw output is preserved; visual defects and subtitles are inspected; exact audio uses the approved master when needed. |

Release evidence consists of Codex Skill validation, strict ShotLoom Skill release validation, plugin package tests, installation-surface tests, and a provider-free forward test.

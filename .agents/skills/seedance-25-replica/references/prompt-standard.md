# Seedance 2.5 复刻提示词规范

## 唯一格式基线

本文件是 ShotLoom Seedance 2.5 复刻 Prompt 的唯一格式事实源，采用 `sd25-pe` 的带参考素材生成结构。内部节奏编号、自动镜头标签、文件名、QC 标签和素材 ID 只存在于追溯记录；最终 Prompt 只保留可直接提交的创作内容。

每个 provider 任务必须独立成立。需要继承的内容绑定到本任务实际提交的 `@图片N`、`@视频N` 或 `@音频N`。

## 先选音频分支

Prompt 编译前只选择一个分支，并与 traceability、请求和成片收尾保持一致。

### `generated_voiceover`

- Seedance 生成已经审核的新口播或要求模型重说的口播。
- 可选的 `@音频N` 只使用干净音色样本的音色、语速和情绪；样本内容不成为台词，也不控制画面或剪辑。
- 事件脚本按语义完整的口播块使用 `{}`。一个口播块绑定一个阶段或一组连续阶段，并且在 Prompt 中只出现一次。

### `original_master_postmix`

- Seedance 只生成画面，原口播母版在视觉验收后直接替换成片音轨。
- provider Prompt 不引用原口播音频、不写 `{台词}`，请求使用 `generate_audio=false`。
- 原台词与阶段的关系只保存在内部 speech groups，供节奏核对与后期对齐，不让模型重新说一遍。

## 参考素材职责

- 宫格分镜负责逐镜头造型、人物姿态、手部位置、产品与状态物体的关键状态、场景、景别和大致构图。
- 人物图只承担用户指定的身份范围；“只锁脸”只采用五官、脸型和脸部身份。
- 产品图负责瓶型、结构、标签、颜色、瓶口和内容物外观，不负责动作。
- 深度默认不用。启用时，唯一 `@视频N` 只负责镜头先后、硬切位置、机位、景别变化和整体运镜节奏；分镜与事件脚本继续承担全部人物、手部、产品、轨迹和状态变化。
- 音频仅在 `generated_voiceover` 分支出现，并只承担干净音色职责。

## 固定输出顺序

1. `【生成目标】`
2. `【参考素材职责】`
3. `【未采用素材】`，仅在存在未采用素材时出现
4. `【主体与道具】`
5. `【事件脚本】`
6. `【保持一致】`

`【保持一致】`只写一个简短正向稳定句。台词分组、局部动作、喷雾物理、硬切和轨迹写在对应职责或阶段中。

## 事件与口播编译

- 每个已接受视觉 beat 在内部 events 中按顺序 exact-once。最终 Prompt 可把场景、核心事件、物体状态和说话模式连续的相邻 beat 合并成一个自然阶段。
- 每个阶段只安排一个主要状态变化，并用“开始状态 → 本段变化 → 可观察结束状态”闭环。
- speech group 使用经过人工语义恢复的自然句、自然分句或独立短句；ASR 文字是逐字证据，不把缺失或错误的 ASR 标点直接当成句界。
- 一个 speech group 绑定一个或多个连续视觉阶段。完整目标台词只在该组首个阶段出现一次，并明确覆盖范围，例如：`从阶段一连续覆盖至阶段三的女性画外音：{我真的恨不得把它焊在脸上}`。
- 每个 `{}` 必须是可以自然说出的完整语义单位。把主谓、动宾、固定搭配、产品词、成分词或数值加单位留成待续残片，判定为失败。
- 所有 speech group 的源文字按顺序拼接后必须还原全部已确认原文；目标文字只应用已声明改词，保持顺序、重复、句式和结尾。
- 用户已经提供新的审核口播时，按新的完整语义块绑定阶段；不把整篇口播再复制到 Prompt 的其他位置。
- 只有用户明确要求数字时间段时才使用连续、不重叠的整数时间段。画幅、总时长、分辨率、帧率、模型名和声音开关属于请求参数。

## 喷雾物理

当阶段包含喷头实际喷洒时，使用同一套可观察过程：`一次按压喷头，液体离开喷口立即分散成均匀细密的雾化微滴，微滴在空气中短暂悬浮后落到皮肤形成极细小水珠`。随后再描述抚匀动作和水润终态。产品图定义喷头结构，事件脚本定义雾化过程。

## 模板

删除未使用的可选行并同步编号：

```text
【生成目标】
生成一段<视频类型>。核心人物是<角色>，使用<目标产品>完成<核心事件>，并以<最终画面>收束。

【参考素材职责】
@图片1为<宫格数量>格分镜，按照<读取顺序>读取；采用逐镜头造型、人物姿态、手部位置、产品关键状态、场景、景别和大致构图，不采用网格、边框或文字标记。连续动作与状态变化按事件脚本执行。
@图片2用于<目标产品>的瓶型、瓶盖、正面标签、颜色和整体外观，不采用参考图背景。
@图片3用于产品打开后的真实瓶口结构和内容物形态，不采用参考图背景。
@图片4用于<角色>的五官、脸型和脸部身份；逐镜头造型以@图片1为准。
@视频1只用于镜头先后、硬切位置、机位、景别变化和整体运镜节奏。全部人物、手部、产品、轨迹和状态变化按@图片1关键状态与事件脚本执行。
@音频1只用于<角色>的干净音色、语速和情绪。实际台词与说话模式按事件脚本执行。

【主体与道具】
<角色>对应@图片4，全片保持同一身份；逐镜头造型按照@图片1变化。
产品对应@图片2和@图片3，全片保持同一种瓶型、瓶口、标签和内容物。

【事件脚本】
阶段一：开始时<状态>；<一个主要事件>；结束时<可观察状态>。从阶段一连续覆盖至阶段三的<角色><画外音/画面内同期口播>：{<完整语义口播块>}

阶段二：承接上一阶段的<状态>；<一个主要事件>；结束时<可观察状态>。

阶段三：<一个主要事件>；结束时<可观察状态>。

阶段四：<一个主要事件>；结束时<最终画面状态>。<角色><画外音/画面内同期口播>：{<下一段完整语义口播块>}

【保持一致】
保持<人物身份与数量、逐镜头造型来源、产品数量与外观、状态物体归属和说话关系>稳定。
```

`original_master_postmix` 使用同一模板，但删除 `@音频N` 行和全部口播句，只保留视觉事件。

## 完成检查

- 固定输出顺序唯一且完整；每份已使用素材都有唯一职责。
- Prompt 不含内部节奏编号、自动镜头标签、文件名、素材 ID 或 QC 标签。
- events 覆盖全部已接受视觉 beat，按顺序 exact-once。
- `generated_voiceover` 的每个 speech group 只出现一组完整 `{台词}`，绑定连续阶段范围；全片拼接逐字等于目标口播。
- `original_master_postmix` 的 Prompt 不含 `{}`、`@音频N` 或让模型复述原口播的指令。
- 深度默认缺席；启用时恰有一个 `@视频N`，职责仅限镜头。
- 喷洒阶段完整描述按压、离开喷口后立即雾化、微滴悬浮和落肤后的极细小水珠。
- `【保持一致】`只有一个简短正向稳定句。
- 当前 Prompt、traceability、可选深度决定和用户指令绑定的 source fidelity QC 为 `PASS`。

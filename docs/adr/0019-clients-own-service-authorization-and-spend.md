# Clients Own Service Authorization and Spend

The first plugin release uses client-owned Service Authorization and client-funded provider quotas for every external understanding, image, audio, and video generation call. Workspace Bootstrap may guide and verify authorization, but credentials are never packaged in the plugin or persisted in Client Workspace or Job artifacts; this requires each client to obtain compatible provider access in exchange for clean cost ownership, revocation, and safe distribution of one unchanged plugin package.

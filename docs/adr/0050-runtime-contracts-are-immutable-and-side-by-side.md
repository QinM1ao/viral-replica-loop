# Runtime Contracts Are Immutable and Side by Side

Each Plugin version declares the Runtime Contracts it may use. A ready Managed Runtime is immutable: normal execution and upgrades cannot install packages, update models, or replace files in place. When a new contract is needed, Bootstrap builds it beside existing versions, validates it completely, and only then atomically changes the Workspace default. Each Job records and retains its selected Runtime Contract in Job Provenance, and a running Job never switches runtime. Compatible Plugin versions may reuse one contract; plugin rollback may reactivate a retained compatible contract. Garbage collection may remove only versions unreferenced by active or resumable Jobs, keeps the current and most recent rollback versions, and never changes the fact that every removed contract is reproducibly rebuildable.

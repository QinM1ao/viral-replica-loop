# Plugin Uses One Canonical Internal Layout

The `viral-replica/` Plugin Package uses one Canonical Plugin Layout: `.codex-plugin/plugin.json`; a root `install.command`; six customer-facing Skill entries under `skills/` (`viral-replica`, `minimax-h3-replica`, `seedance-25-replica`, `seedance-run`, `video-shot-refinement`, and `video-subtitle-removal`); the complete private workflow implementation under `engine/` with craft, tools, workflows, workers, and rules; Built-in Profiles under `profiles/builtin/`; initialization material under `workspace-template/`; installation, upgrade, and diagnostic utilities under `scripts/`; non-client Product Fixtures under `assets/fixtures/`; and product `tests/` and `docs/`. Plugin Creator defines and validates the Codex-facing shell, while compatibility adapters preserve the existing workflow behavior during migration. Client references, Jobs, generated media, QC evidence, deliveries, secrets, and `workspace-dev/` are prohibited from this tree.

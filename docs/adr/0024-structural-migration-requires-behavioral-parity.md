# Structural Migration Requires Behavioral Parity

The plugin/workspace migration passes only with Behavioral Parity: deterministic rules, reference bindings, director plans, prompts, audio boundaries, provider requests, lifecycle decisions, approvals, QC conclusions, and delivery contents must be exactly equivalent for fixed fixtures. New stochastic media is not required to be pixel-identical, but it must use equivalent providers, models, inputs, settings, and acceptance thresholds and reach the same QC class; all existing accepted media and evidence remain unchanged.

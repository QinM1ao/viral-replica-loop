# Package Conforms to the Codex Plugin Model

The deliverable will be a real Codex Plugin Package using the supported manifest, packaged Skills, optional app dependencies, installation lifecycle, and permission model, rather than a repository archive branded as a plugin or a custom loader. Access to and complete reading of the official Plugin Creator and validation guidance is an implementation gate: until then the work remains design-only; current installed Codex plugins may inform compatibility but cannot substitute an undocumented parallel format.

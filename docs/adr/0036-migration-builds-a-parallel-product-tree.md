# Migration Builds a Parallel Product Tree

The plugin/workspace architecture will be assembled in a Parallel Product Build beside the current dirty `viral-replica-loop/` checkout, which remains an unchanged comparison and recovery baseline throughout migration. Files are inventoried and copied or transformed into the new `viral-replica/` Plugin Package and sibling `workspace-dev/` Development Workspace, and only a tree that passes Behavioral Parity becomes the formal product; cleanup or archival of the legacy checkout is a later explicit decision.

# Only Active and Proof Jobs Are Normalized

Active Jobs and selected maintained proof cases are converted into the current Job Archive model, while all other historical outputs, deliveries, experiments, and research move intact into a read-only Legacy Archive with an origin and classification manifest. This leaves some history in its original shape, but avoids fabricating Reference Bindings, Job Provenance, or modern QC for work that never produced them and allows a specific legacy item to be normalized later when it has a real consumer.

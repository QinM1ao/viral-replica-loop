# Workspace and Provider Readiness Are Independent

Workspace Bootstrap uses layered readiness. A Client Workspace becomes ready when its Schema, writable customer boundary, and local managed runtime pass, even when one or more external Provider Capabilities are not configured. Source understanding, image generation, asset transport, video generation, and subtitle removal each maintain an independent readiness state. Missing or invalid authorization blocks only the first stage that actually requires that capability and presents its configuration path; it does not invalidate the Workspace, prevent Job creation, or block unrelated local and provider-backed work. This avoids forcing clients to configure optional Seedance API or MediaKit access when their selected handoff and media do not require them.

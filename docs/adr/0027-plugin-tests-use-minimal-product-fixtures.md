# Plugin Tests Use Minimal Product Fixtures

The Plugin Package may contain minimal Product Fixtures and expected deterministic artifacts needed to validate itself without `workspace-dev/`, provided they are synthetic, licensed, or anonymized and do not reproduce a live or historical client Job. All real source media, person and product references, generated media, run evidence, and deliveries remain workspace-owned; this duplicates only deliberately small test inputs in exchange for independent release checks and safe workspace deletion.

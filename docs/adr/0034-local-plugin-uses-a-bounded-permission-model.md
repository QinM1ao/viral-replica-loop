# Local Plugin Uses a Bounded Permission Model

Local Plugin Execution may read only user-selected external source paths for Reference Import, write the active Client Workspace and a rebuildable managed runtime area, execute declared plugin media tools, and reach declared model-provider endpoints. Imported Jobs use workspace-owned reference versions, unrelated repositories and workspaces remain out of scope, and paid external generation still requires Generation Approval; this adds explicit import and permission handling in exchange for safe direct installation.

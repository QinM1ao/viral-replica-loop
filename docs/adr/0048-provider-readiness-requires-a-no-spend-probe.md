# Provider Readiness Requires a No-Spend Probe

A Provider Capability may be marked Ready during Workspace Bootstrap only after a provider-specific No-Spend Capability Probe succeeds. Probes use non-billing read-only account, project, permission, and reachability operations whenever available; the TOS transport capability may create a synthetic non-client object to prove write, read, deletion, and post-deletion absence. Bootstrap never creates image, video, subtitle, or other paid generation tasks merely to test credentials. When a provider offers no safe verification route, the Service Authorization Profile remains Configured but Unverified and may become Ready only after a separately authorized real operation succeeds. Probe evidence contains status, time, non-secret project identity, and normalized error categories, never Credential Material or secret-bearing raw responses.

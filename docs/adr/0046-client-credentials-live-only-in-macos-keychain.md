# Client Credentials Live Only in macOS Keychain

The first supported release persists client Credential Material only in macOS Keychain, scoped by immutable Workspace identity and provider. Workspace Bootstrap collects credentials after plugin installation, stores only non-secret Service Authorization Profile status in the Client Workspace, and retrieves each secret just in time into the exact provider subprocess environment. Plugin files, Workspace files, Job evidence, logs, shell startup files, global configuration, and plaintext fallback stores are prohibited. Environment variables may be accepted only as an explicit process-lifetime override and are never imported into persistent state. A denied or unavailable Keychain fails closed, and revocation deletes the Keychain item and invalidates the corresponding authorization state.

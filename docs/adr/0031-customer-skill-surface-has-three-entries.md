# Customer Skill Surface Has Six Entries

The customer-facing plugin exposes one primary `viral-replica` Skill for complete replication, explicit `minimax-h3-replica` and `seedance-25-replica` model routes, one `seedance-run` continuation for ordinary Seedance 2.0 API generation, plus bounded `video-shot-refinement` and `video-subtitle-removal` specialist Skills. The MiniMax H3 entry owns direct Ref2VA replication only when the user names MiniMax H3. The Seedance 2.5 entry owns the up-to-30-second unit split, matching depth action-and-camera references, standard prompts, upload packs, and the verified Wujie `taskCode=2509` submission/poll/download route. Both generation routes may enter paid generation only through the canonical approval, preflight, reservation, fanout, persistence, and unknown-outcome STOP contracts. The remaining craft method, provider checker, Workspace Bootstrap, and maintainer improver stay internal.

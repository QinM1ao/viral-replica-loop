# Usable Artifacts Advance

A Job Run advances whenever the next stage has current-Job Usable Artifacts, even if Semantic QC reports a visual or creative defect. Image work gets one targeted retry for the affected defect scope, then continues with the best usable candidate and a Visual Warning; only missing, unreadable, invalid-format, wrong-Job, stale-bound artifacts or missing paid authorization stop. This deliberately trades perfect pre-generation quality for continuous progress and bounded runtime.

# Private Release Uses One-Folder Installation

The first Private Plugin Release is delivered as exactly one versioned `shotloom/` Plugin Package with one bundled local installation command. Installation places a managed copy in the supported local plugin location, creates or updates the client's personal marketplace registration using the Plugin Creator-compatible schema, validates that Codex can discover the plugin, and tells the client to start a new Codex task. Installation exposes the existing replication skill as `shotloom:viral-replica`, which distinguishes this product from legacy unnamespaced copies without migrating the established workspace schema. The client does not need Plugin Creator, Git, a vendor backend, `workspace-dev/`, or manual marketplace editing; development and release validation still use Plugin Creator as the authoritative scaffold and conformance tool.
